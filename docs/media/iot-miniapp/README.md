## 使用边界

- 这些是连接演示环境后的应用界面，不是全新安装自动生成的数据；菜单、设备、属性和访问范围依赖平台配置与账号授权。
- 原图保留 vConsole 等调试标识。官网和文档目前选用设备列表、数据分析及自动化条件三张；不要用 AI 补画或改写读数、设备状态、控件和执行结果。
- 自动化截图只证明条件配置入口可见，不代表规则已保存或执行；属性页的控制按钮不证明已操作真实设备，亦不作为配网、OTA 等功能的验收记录。
- ur-kit 公开的是应用客户端、业务后端示例、SDK 与开发材料。Core、Things 基础平台服务实现不在本素材所述的开源范围内。

## 官网与文档站复用

两站均将展示用的三张原图放在各自的 `public/showcase/iot-miniapp/` 静态目录，文件名保持一致，可独立部署。更新素材时从本目录复制，并用 manifest 中的 SHA-256 核对；站内图注保留演示环境、调试状态与权限前提。

页面缩略图应保持宽高比，提供查看原图的入口，不用截图中的按钮作为网页操作控件。
